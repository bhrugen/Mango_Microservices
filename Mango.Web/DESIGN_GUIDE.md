## 💡 Tips for Using This Design

### Adding New Cards
```html
<div class="card">
	<div class="card-body">
		<h5 class="card-title">Title</h5>
		<p class="card-text">Content</p>
		<button class="btn btn-primary">Action</button>
	</div>
</div>
```

### Using Gradient Buttons
```html
<button class="btn btn-success">Green Gradient</button>
<button class="btn btn-primary">Purple Gradient</button>
<button class="btn btn-warning">Pink Gradient</button>
```

### Adding Icons
```html
<i class="bi bi-cart"></i>
<i class="bi bi-heart-fill"></i>
<i class="bi bi-star-fill"></i>
```
